# 学习抽卡银行

学习换游戏时间和抽奖券的个人网页应用。纯 HTML / CSS / JavaScript，无需构建，直接作为静态网站部署即可。

- `index.html`：页面与样式
- `logic.js`：奖励规则
- `voices.js`：同伴台词
- `app.js`：界面与存储
- `sprites/`：同伴立绘

迁移与部署说明见 [MIGRATION.md](MIGRATION.md)。个人数据不在仓库里，请用页面里的"导入备份"恢复。
